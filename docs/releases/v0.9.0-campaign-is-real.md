### The campaign screen

While the management screen is up, the tactical simulation is frozen and the
campaign clock ticks instead:

- **`M`** — toggle between the tactical board and the world map.
- **Click** a territory to select it (its name, owner, mission, tax, and status
  show in the sidebar).
- **`-`** / **`+`** — lower / raise the selected territory's tax.
- **`B`** — open the **R&D shop**: **Up/Down** move through the research tree and
  the equipment catalogue, **Left/Right** pick the squad slot, and **Enter**
  funds a research node or buys and assigns the selected gear. **`Esc`**/`B`
  closes it.
- **`D`** — deploy the selected territory's mission (starts the tactical board
  with your bought loadout).
- **`R`** — recruit an agent, taking a fixed name from the selected region's pool.
- **`F5`** / **`F9`** — save / load the campaign (the in-play save path).
- **`Esc`** — quit.

### Saving and loading

- **`F5`** saves the campaign and **`F9`** loads it **on the world map**. On the
  tactical board the keys print a one-line hint instead — a mission is transient,
  so there is no progress to save there.
- The default slot is a per-user file (`SDL_GetPrefPath`, on Linux
  `$XDG_DATA_HOME/FOSSynd/fossynd/save.json`). An explicit `--save <path>`
  overrides it; `--load <path>` resumes that file and the keys then continue it.
- In-game saves **fail soft**: a bad path prints a message and play continues, so
  a mis-keyed save never costs you progress. The CLI `--load` is stricter: naming
  a missing file is a hard error, and a corrupt or mismatched save is rejected.

### The new-game screen

On a fresh campaign the game asks you to **name your syndicate** (type it;
**Backspace** edits; printable ASCII, up to 24 characters) and **cycle a logo**
(**Left/Right**), then **Enter** begins. Leave the name empty to keep the
data-authored default. `--load` skips the screen because the save restores your
identity; `--new-game` forces it.

## 3. Install a runnable copy (recommended)

The game is a single self-contained executable, but its missions, catalogues,
locales, and **metagame world data** are also shipped as data so they can be
edited without rebuilding. `cmake --install` puts them in the standard places:

```bash
sudo cmake --install build --prefix /usr/local
# -> /usr/local/bin/FOSSynd
# -> /usr/local/share/fossynd/missions/*.json      (every shipped mission)
# -> /usr/local/share/fossynd/world/*.json         (campaign, world, research, equipment, names)
# -> /usr/local/share/fossynd/weapons.json, agents.json, vehicles.json
# -> /usr/local/share/fossynd/lang/*.json          (en + de)
# -> /usr/local/share/fossynd/fossynd.conf.example
```

Run it from anywhere:

```bash
FOSSynd
```

It finds its mission and campaign via the built-in fallback search
(`/usr/local/share`, `/usr/share`, next to the binary, repo-relative) and falls
back to the embedded copy if none is found — so it still runs if you only copy
the binary.

## 5. Controls

### Tactical board

- **Left-click** — move the squad (or select an agent under the cursor).
- **Left-drag** — box-select every agent inside the rectangle (shift-drag adds).
- **Shift + click** — append a waypoint to the selection's route (drawn on screen).
- **Keys `1`–`4`** — recall control group 1–4; **Ctrl + `1`–`4`** assign it.
  **`5`–`8`** select the 1st–4th living agent. **`A`** selects all.
- **Right-click** (or click) an enemy — order the selection to attack it.
- **`P`** — persuade the nearest civilian with the selection (recruit a follower).
- **`F`** — release the followers of the selected agents.
- **`H`** / **`S`** / **`C`** — use a **medikit** / raise a **shield** /
  run a **scanner** pulse on the selection.
- **`[` / `]`** — cycle the active **drug bar** (adrenalin / intelligence /
  physical); **`;` / `'`** lower / raise it for the selection.
- **`E`** — hijack the nearest vehicle in range, or step out if already driving.
- **`+` / `-` or the mouse wheel** — zoom the view (1x/2x/3x, nearest-neighbour).
- **`F11`** — toggle fullscreen.
- **`Space`** — pause / resume the simulation.
- **`M`** — open the campaign management screen.
- **Arrow keys** — scroll the camera. **`R`** — restart. **`Esc`** — quit.
- **`--demo`** — attract mode: the squad fights on its own.

### Campaign management screen

- **Click** a territory to select it; **`-`**/**`+`** change its tax; **`B`** opens
  the R&D shop; **`D`** deploys; **`R`** recruits an agent; **`F5`**/**`F9`**
  save/load; **`M`** returns to the tactical board; **`Esc`** quits.

> The **shield**, **medikit**, and **scanner** are bound to **`S`**, **`H`**, and
> **`C`** on the tactical board, and also reach a mission through a bought
> **loadout** (the R&D shop). Performance **drugs** are the three regulated bars
> (**`[`/`]`**, **`;`/`'`**) rather than a consumable.
