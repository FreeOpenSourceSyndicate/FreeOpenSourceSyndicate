# v0.3.0 — "Bystanders"

**Release date:** 2026-10-13 · **Branch:** `release/v0.3.0-bystanders` · **Tag:** `v0.3.0`

These instructions are **specific to this release**. If you are building `main`
or another version, use [`docs/BUILD.md`](../BUILD.md) instead.

## What is new in this version (visible difference)

A playtester who has seen v0.2.0 should notice these immediately:

1. **Civilians are on the map.** Pale bystanders wander the streets. They are
   not combatants: they are never targeted and never affect win/lose.
2. **They react to gunfire.** Fire a weapon near a civilian and it panics and
   runs. A stray shot can kill one.
3. **The HUD shows collateral.** Kill a civilian and the top bar starts
   counting `COLLATERAL: N`, so you can see (and avoid) civilian deaths.
4. **The version is on screen.** The window title and the HUD both read
   `v0.3.0`, so you can confirm at a glance you are running *this* build and not
   an older one.
5. **A low-spec build/flag exists** for very old hardware (see below).

## What you need

- A Debian-based Linux machine (Mint, Ubuntu, Debian) — the primary, tested
  platform.
- `git`, a C++17 compiler, `cmake` (>= 3.15), and `libsdl2-dev`.
- No GPU and no game assets are required: the game draws itself and embeds its
  own font.

## 2. Build and play (standard)

```bash
sudo apt-get update
sudo apt-get install -y build-essential cmake git libsdl2-dev

cmake -S . -B build -DFOSS_BUILD_GAME=ON -DCMAKE_BUILD_TYPE=Release
cmake --build build -j"$(nproc)"

./build/src/FreeOpenSourceSyndicate          # play
./build/src/FreeOpenSourceSyndicate --demo   # hands-off attract mode
ctest --test-dir build --output-on-failure   # should report 4/4 tests passed
```

### Old hardware (low-spec)

```bash
cmake -S . -B build -DFOSS_BUILD_GAME=ON -DFOSS_LOW_SPEC=ON -DCMAKE_BUILD_TYPE=Release
cmake --build build -j"$(nproc)"
./build/src/FreeOpenSourceSyndicate          # 320x200 window, software renderer
```

You can also run any build in low-spec mode at runtime with `--low-spec`.

## 3. Copy a runnable copy to another computer

The game is a **single self-contained executable**. It loads no external files
at runtime (no assets, no config, no font file), so the only thing to copy is the
binary. SDL2 must be present on the target machine.

On the build machine, collect the two files you need into one folder:

```bash
mkdir -p foss-v0.3.0
cp build/src/FreeOpenSourceSyndicate-0.3.0 foss-v0.3.0/   # the real file
cp build/src/FreeOpenSourceSyndicate       foss-v0.3.0/   # the symlink (optional)
```

Then copy that folder to the other computer — e.g. with `scp`:

```bash
scp -r foss-v0.3.0 user@other-host:/home/user/
```

or a USB stick:

```bash
cp -r foss-v0.3.0 /media/$USER/USBSTICK/
```

On the target machine:

```bash
# Debian/Ubuntu/Mint — the one runtime dependency
sudo apt-get install -y libsdl2-2.0-0

cd /home/user/foss-v0.3.0
chmod +x FreeOpenSourceSyndicate-0.3.0
./FreeOpenSourceSyndicate-0.3.0
```

> If the binary is on a different architecture or a much older libc than the
> build machine, build it on the target instead (step 2) — copying a binary
> across very different Linux versions can fail. The source and the build are
> tiny, so building in place is always an option.

## 4. Controls

- **Left-click** — move the squad (or select an agent under the cursor).
- **Shift + click**, keys **1**–**4**, **A** — select individual agents / all.
- **Right-click** (or click) an enemy — order the selection to attack it.
- **Arrow keys** — scroll the camera. **R** — restart. **Esc** — quit.
- **`--demo`** — attract mode: the squad fights on its own.
