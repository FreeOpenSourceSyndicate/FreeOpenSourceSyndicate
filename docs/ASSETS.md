# Asset Registry & Pipeline

All game assets live under `assets/`. This file is the **registry**: every asset
must be listed here with its license and provenance, or it must not be committed.

Read `docs/LEGAL.md` first. The short version: **original or explicitly licensed
only. Never ripped from the original games.**

## Directory layout

```
assets/
  sprites/     # agents, civilians, vehicles, structures, effects
  tiles/       # isometric terrain tiles
  ui/          # HUD, menus, icons, fonts
  audio/       # sfx and music
  data/        # gameplay data (weapons.json, agents.json, missions/*.json)
```

## Rules

1. **No unregistered assets.** If it is in `assets/` and not in the table above,
   the PR will be rejected.
2. **License must be MIT-compatible** (CC0, CC-BY, CC-BY-SA only if it does not
   force the game to be share-alike in a way we cannot accept — prefer CC0/CC-BY).
   GPL/AGPL/unknown = not allowed.
3. **AI-generated assets** must record the tool and the exact prompt, and the
   tool must permit commercial use. See `docs/LEGAL.md`.
4. **Naming.** No names, logos, or text copied from the original games.
5. **Placeholders** should be clearly marked and use an obvious temp style, so we
   do not accidentally ship them as final.

## Placeholder strategy

Until real art exists, prefer **procedurally drawn primitives** (like the current
`DrawNode` circles/diamonds) over downloaded art. They are guaranteed original,
tiny, and zero-legal-risk. Put them behind a "debug/placeholder" flag where
practical.

## Data assets

`assets/data/*` is gameplay content, not binary art. It is subject to the same
no-copying rule: re-implement the *numbers*, do not copy the original tables.
Format/schema is decided by ADR-0003.
